# 立体と展開図ラボ (Math Solids Lab)

小学校1〜6年生の算数（箱の形、直方体・立方体の展開図、角柱・円柱・角錐・円錐、回転体、立体の切断面）を3D空間と「組み立てスライダー」で直感的に体験できるWebアプリケーションです。

デザインは `../math-quiz/`（算数チャレンジ）と同じ「方眼ノート・原稿用紙と赤ペン・蛍光マーカー（ダークモード時は黒板とチョーク）」のトーンで統一されており、PC・タブレット・スマートフォンのすべてで崩れずに操作できます。

## 主な機能

1. **全学年共通コア機能**
   - **組み立てスライダー (`0%` 平らな展開図 ⇔ `100%` 閉じた立体)**: 指やマウスで無段階に往復し、面が折れ曲がる過程をコマ送りのように確認可能。
   - **自由な3D視点回転・ズーム**: 1本指スワイプで360度回転、ピンチ・ホイールで拡大縮小、「ななめ視点」「真上から」のワンタップ切り替え。
   - **面・辺・頂点の「対応ハイライト」**: 展開図上でタップした面・辺・頂点が、組み立てたときに重なる・向かい合う相手と同じ色で発光（ヒントON/OFF切替可）。
   - **「失敗」の物理リアクション**: 立方体にならない展開図では、スライダーを進めると面と面がぶつかって赤く光り、「ガチン！」と反発バウンスして、空いたままの穴が赤い破線で表示されます。

2. **学年別コンテンツ & サンドボックス**
   - **1〜2年生（はこパズル・スタンパー）**
     - **はこころがし・スタンパー**: 箱をパタンパタンと転がして床に絵の具のスタンプを押し、展開図を作って組み立てる。
     - **さいころ動物シールあて**: 開いた面に動物シールを貼り、閉じたとき反対側にくる動物を当てる。
   - **3〜4年生（立方体ビルダー & まちがい探し）**
     - **組み立て判定ゲーム**: 提示された展開図が「立方体になる⭕」か「重なって失敗する❌」かを予想してスライダーで検証。
     - **11パターン収集手帳**: 立方体の全11種類の展開図（1-4-1型6種、2-3-1型3種、2-2-2型1種、3-3型1種）をパズルで探して図鑑を埋める（回転・裏返し同型判定付き）。
     - **頂点・辺マッチング**: 立体にしたとき「赤い点A」と重なる頂点をタップで当てる。
   - **5〜6年生（立体クラフト & ぐるぐる回転体）**
     - **曲面・多角形の展開図**: 円柱の側面（長方形）がくるっと丸まるアニメーションや、円錐・三角柱・六角柱・正四角錐・正四面体の折りたたみ。
     - **ぐるぐる回転体レーサー**: 回転軸に平面図形（長方形、直角三角形、半円、台形、穴あき長方形）をセットし、高速スピンで浮かび上がる回転体を観察。
     - **立体カッター（切断面ラボ）**: 立方体を好きな角度と高さでスライスし、正方形・長方形・正三角形・二等辺三角形・五角形・正六角形の切り口を発見。
   - **全学年（じゆうさくせい / サンドボックスモード）**
     - 6×6の方眼マスに面を自由に並べてシールやサイコロの目を貼り、折れ角も調整してオリジナル立体を組み立て。

## 開発コマンド

```bash
# 依存パッケージのインストール
npm install

# 開発サーバー起動
npm run dev

# 単体テスト実行 (Vitest)
npm test

# 本番ビルド (TypeScript型チェック + Vite Build)
npm run build
```
